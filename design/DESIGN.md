# Rozmovio — специфікація редизайну

Джерело правди — HTML-макети в `mockups/`. Відкрий їх у браузері й звіряй результат піксель у піксель. Цей файл пояснює правила, яких з макета не видно.

| Макет | Що це |
|---|---|
| `mockups/01-landing.html` | Сайт rozmovio.com, головна (1440px) |
| `mockups/02-inbox.html` | Кабінет → Чати |
| `mockups/03-reports.html` | Кабінет → Звіти |
| `mockups/04-channels.html` | Кабінет → Канали |

Токени — `tokens.css` (CSS-змінні `--rz-*`). Жодних хардкод-кольорів у компонентах, лише змінні.

## 1. Загальні правила

- Шрифт — **Onest** (400/500/600/700) для всього, **JetBrains Mono** 500 — телефони, ID, ключі, хоткеї.
- Прибрати всі градієнтні фони, blur-плями, радіальні заливки, градієнтні бульбашки повідомлень. Єдиний градієнт — у самому логотипі.
- Картки: білий фон + рамка `--rz-border` 1px, без тіні. Тінь — лише у того, що висить поверх (поповери, composer, toast).
- Одна primary-кнопка (`--rz-primary`) на екран. Решта — secondary (білий фон, рамка `--rz-border-strong`) або icon-only.
- Фіолетовий (`--rz-violet*`) — тільки для ШІ-функцій. Помаранчевий — тільки «чекає відповіді» та лічильник у навігації.
- Статус завжди = крапка/іконка + слово. Колір сам по собі нічого не означає.
- Числа — `font-variant-numeric: tabular-nums`.
- Текст ніколи не переноситься в кнопках, чипах, табах: `white-space: nowrap`. Довгі імена — `text-overflow: ellipsis`.
- Фокус: `outline: 2px solid var(--rz-primary); outline-offset: 2px` на всьому інтерактивному.
- Іконки — Lucide (lucide.dev), stroke 1.75, round caps; 16px у кнопках, 20px у навігації.

## 2. Каркас кабінету

```
┌──────┬────────────┬──────────────────────────┬───────────┐
│ nav  │  список    │  розмова                 │  клієнт   │
│ 76px │  348px     │  flex: 1                 │  320px    │
│ navy │  white     │  bg #F6F7FB              │  white    │
└──────┴────────────┴──────────────────────────┴───────────┘
```
Інші сторінки (Звіти, Канали, Налаштування…): nav 76px + контент з padding `36px 48px`.

### Ліва навігація (`--rz-navy`)
- Зверху знак `assets/rozmovio-mark-white.svg` 28px, відступ 18px знизу.
- Пункт: 60px шириною, іконка 20px + підпис 11px/500, radius 12px, колір `--rz-nav-icon`.
- Активний: фон `rgba(255,255,255,0.12)`, текст білий.
- Лічильник непрочитаного: кружок 16px `--rz-attention`, цифра 10px/700 кольору navy, у правому верхньому куті пункту.
- Внизу: дзвіночок, налаштування (icon-only 40px, `aria-label`), аватар користувача 34px.
- Пункти: Чати, Канали, Сценарії, Шаблони, Звіти, CRM (було «Інтеграції»), Гроші. «Власник» і «Гроші» — лише для ролі Власник: ховати, не дизейблити.

## 3. Екран «Чати»

### Колонка списку
- Заголовок «Чати» 22px/700, праворуч дві кнопки 34px: фільтри (secondary) і «+» (navy).
- Пошук: висота 38px, фон `--rz-surface-2`, radius 10px, іконка лупи, справа хінт `⌘K` моноширинним у рамці.
- **Фільтр — сегментований контрол**, а не окремі чипи: трек `--rz-surface-2`, padding 3px, radius 10px; 4 рівні сегменти `flex: 1 1 0` висотою 30px: «Відкриті 16 · Мої 4 · Вільні · Закриті». Активний — білий, `--rz-shadow-sm` + рамка 1px `#E6E9F0`, число в активному — `--rz-primary`.
- Рядок діалогу: padding `14px 20px`, аватар 42px (кольоровий фон + ініціали), у правому нижньому куті мітка каналу 18px з білою обводкою 2px.
  - Непрочитаний: ім’я 700, прев’ю 500 кольору `--rz-text`, час `--rz-primary` 600, справа лічильник 20px `--rz-primary`.
  - Чекає відповіді: замість лічильника пігулка `--rz-warning-soft` / `--rz-warning` з іконкою годинника і «18 хв».
  - Вибраний: фон `--rz-selected` + індикатор 3px зліва `--rz-primary`.
  - Прочитаний: ім’я 600, прев’ю `--rz-text-2`, час `--rz-text-3`.

### Шапка розмови (72px, білий)
- Ім’я 16px/700; під ним мітка каналу 14px + «Telegram · телефон · у мережі» 13px.
- Праворуч: селект статусу (secondary), «Бот» із зеленою крапкою-індикатором, «Закрити» (icon-only ✓ з `aria-label`), **«Взяти собі»** (primary). Коли діалог уже на мені — замість primary показати «Передати» (secondary).

### Повідомлення
- Вхідне: зліва, білий + рамка `--rz-border`, radius `18 18 18 6`, аватар клієнта 28px біля останнього в серії.
- Вихідне: справа, `--rz-primary`, білий текст, radius `18 18 6 18`; мета `#C9D5FF`.
- Цитата у повідомленні: ліва лінія 2px напівпрозора, автор жирним.
- Послідовні повідомлення одного відправника — проміжок 8px, у середніх кут до відправника теж 6px.
- Системні події («Костянтин взяв діалог · 16:45») — по центру, 12px `--rz-text-3`, з лініями з боків.
- Макс. ширина бульбашки 460px.

### Composer
- Картка: білий, рамка `#DDE1EA`, radius 16px, `--rz-shadow-card`, відступ 24px від країв.
- Верхній ряд чипів: «Запропонувати відповідь» (ШІ, фіолетовий), далі 2–3 найуживаніші шаблони (`/назва`, фон `--rz-surface-2`).
- Textarea без рамки, 14px/21px, автовисота.
- Нижній ряд: файл, емодзі, шаблони (icon-only 34px), роздільник, «Нотатка для команди»; праворуч хінт «Enter — надіслати» і primary «Надіслати →».

### Права панель клієнта
Секції, розділені лінією `--rz-divider`, заголовки 11px/700 uppercase letter-spacing .07em `--rz-text-3`:
1. Аватар 64px, ім’я 17px/700, «Клієнт з …», кнопки-посилання «Zoho» і «Замовлення».
2. **Контакт** — пари ключ/значення 13px; телефон моноширинним; відсутнє значення = посилання «+ додати».
3. **Zoho CRM** — блок `--rz-surface-3` radius 12px: Запис / Етап / Відповідальний.
4. **Мітки** — пігулки 26px + пунктирна «+ мітка».
5. **Нотатки команди** — жовтий блок `--rz-note-bg`.

## 4. Звіти
- Шапка: заголовок 28px/700 + підзаголовок; праворуч сегмент 7/30/90 днів (активний — navy), селекти «Усі канали», «Усі співробітники», secondary «CSV» з іконкою.
- Таби (Огляд, Коли пишуть, Канали, Команда, SLA): підкреслення 2px navy у активного.
- Рядок KPI: 4 картки, число 36px/700.
- «Час першої відповіді»: 4 метрики в одній рамці з вертикальними роздільниками (медіана — `--rz-primary`), нижче гістограма: трек `--rz-surface-2` 28px, заливки від `--rz-primary` до світліших відтінків.
- «Закриття»: кільцева діаграма + 2 числа.
- Темна картка (navy) з головним висновком і кнопкою переходу («Без відповіді — 3 діалоги → Відкрити в чатах»).

## 5. Канали
- Сітка 3 колонки, gap 16px. Картка: іконка каналу 44px radius 12px, назва 15px/700, тип 13px, праворуч перемикач 36×20.
- Низ картки через роздільник: статус (крапка + «Працює · 1 діалог») і посилання «Налаштувати».
- Остання клітинка — пунктирна «Додати канал».
- Над сіткою рядок-зведення: «8 підключено · 7 працюють · 1 без діалогів».

## 6. Сайт
Структура зверху вниз: навігація 76px → hero (бейдж «Нове», H1 72/76 700 letter-spacing −0.035em, підзаголовок 20px, 2 CTA 52px, під ними скриншот продукту в рамці з тінню та двома плаваючими картками) → рядок каналів → bento-сітка можливостей (3 колонки, одна картка на 2 колонки, одна темна) → «Запуск за один вечір» (3 кроки з номерами моноширинним) → темна секція CRM (radius 32px, текст + мокап картки клієнта) → ціни (3 колонки, рекомендований — рамка 2px `--rz-primary`, бейдж зверху) → CTA-блок `#F4F6FC` → футер.
Заглушки `[ЦІНА]`, `[ЛІМІТ КАНАЛІВ]`, `[EMAIL ПІДТРИМКИ]` — замінити реальними даними.

## 7. Чого НЕ робити
- Не змінювати бізнес-логіку, API, назви полів і роути — тільки візуальний шар і розмітку.
- Не додавати нових фіч, яких нема в продукті (якщо в макеті є елемент без бекенду — напр. «Нотатка для команди», «у мережі», ⌘K — зробити UI і позначити TODO, або прибрати, спитавши).
- Не малювати логотипи месенджерів — лише кольорова мітка з простою іконкою, як у макеті.
- Не використовувати Inter/Roboto, градієнти, glassmorphism, емодзі в інтерфейсі.
